# Second-author audit

`second_author_audit_labels.csv` — the 200 cells of the blind
Presence-only audit by the second author (random 100 / hard 100),
with the second author's gate decisions, labels, and rationales.
`sample_reason` records how each hard-subset cell was selected
(human-vs-both-judges disagreement 50, judge-split adjudications 30,
rubric-boundary heuristics 20), matching the composition described in
the paper. Audit instructions:
`../../experiment/second_author_audit_instructions.md`.
