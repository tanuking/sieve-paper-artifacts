# Slot-Local Rubrics

One YAML file per sampled meeting (MTG01-MTG50). Each file wraps the
meeting-specific evaluation instrument for all seven slots: Topic Gate /
Quality Gate labels with meeting-specific match / not_match wording,
the fact_check_target (fields, valid items, notes), score examples, and
answer-locality context.

Rubrics were authored from the completed event sheet and
`../../method/slot_semantics.json`, following
`../../method/slot_local_rubric_authoring_protocol.md`, and validated
under `../../method/slot_local_rubric_validation_protocol.md`. A few
files carry meeting-specific `notes` (for example, meetings whose
source leaves no pending handling path for slot U).
