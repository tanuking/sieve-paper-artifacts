# Third-Party Licenses and Redistribution Notes

- MeetingBank: raw transcripts are not redistributed. This package includes MeetingBank segment identifiers and dataset-provided reference summaries for diagnostic comparison. Verify MeetingBank license terms before redistributing additional source content.
- LLM provider outputs: generated summaries are redistributed as research artifacts for reproducibility. No API keys, request IDs, or private provider logs are included.
- ROUGE, BERTScore, and sentence-transformer metrics: this package includes computed metric tables; users installing optional metric libraries should follow those projects' licenses.
- Scripts in `scripts/` are released under the repository license.
